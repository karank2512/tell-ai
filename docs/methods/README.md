## Backtest reports (spec section 13)

`tell backtest <name> [--as-of DATE] [--out DIR] [--refresh]` writes `<name>-<YYYY-MM-DD>.md` and a full copy as `<name>-latest.md` (only when no newer dated report is already in the directory, so a regenerated past date never moves the pointer back; the dated file is the citable source). `tell backtest refresh` (also spelled `tell backtest --refresh`) writes every public report. The weekly workflow runs it with `--out tell-data/site/methods` and commits the reports to [tell-data](https://github.com/karank2512/tell-data/tree/main/site/methods), never here (ADR 0025); the index below lists only reports a maintainer regenerated by hand into this directory. The per-command `--refresh` flag means something narrower: fetch external inputs missing from the cache. Only `velocity-lead --refresh` fetches anything (Wayback CDX listings into `tell-private/cache/wayback`), and the weekly workflow never passes it and has no `tell-private` checkout, so the Wayback reconstruction in 13.2 is fetched only by a maintainer running `tell backtest velocity-lead --refresh` locally; `weekly.yml` reads the cache only and reports unfetched boards as such. Templates: `docs/methods/templates/`. Each report states the question, the cohort, N, the query or script, the numbers, the caveats and the date. A number with N under 30 is printed as "(N=12; too small to quote)" and the report's front matter then says `quotable: false`; launch drafts and resume lines quote only `quotable: true` reports.
