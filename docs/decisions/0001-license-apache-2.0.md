# 0001. License is Apache-2.0

- Status: accepted
- Date: 2026-10-05

## Context

SPEC section 17 defaults to MIT. The project wants an explicit patent grant for contributors and users.

## Decision

License the repository under Apache-2.0 (deviation from the spec default of MIT).

## Consequences

LICENSE holds the Apache-2.0 text with copyright 2026 Karan Kapur; the pyproject classifier says Apache Software License; source headers policy follows Apache-2.0. Dependencies must be license-compatible.
